# Norway Waypoint Plan

## 基準となる GPS 直進コース

| 項目 | 緯度 | 経度 |
| --- | ---: | ---: |
| 基準点 / start | 63.4420936 | 10.4242793 |
| 進行先 / goal | 63.4416044 | 10.4238816 |

このコースは、基準点から goal へ向かう直進を、今後のウェイポイント配置の
基準線とする。

## ローカル座標での見積り

地球半径 6,371,000 m の球面近似により、start から goal への差分は次のとおり。

| 値 | 見積り |
| --- | ---: |
| 距離 | 57.88 m |
| 真方位 | 199.98° |
| 東向き差分 | -19.77 m |
| 北向き差分 | -54.40 m |

したがって、start をローカル座標の原点 `(0, 0)` とする場合、goal はおよそ
`(-19.77, -54.40)` m に置ける。以降の WP は、この基準線上、またはこの基準線
からの横方向オフセットとして定義する。

> この文書はウェイポイント検討用の初期値であり、実船で使う前に測位系の map
> 原点、方位の定義、現地の安全域を確認する。
