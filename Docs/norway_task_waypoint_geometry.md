# ノルウェー Task WP — 競技図に基づく配置案

開始 GPS 1/5/7 を `63.4420936, 10.4242793`、GPS 2/6 を
`63.4416044, 10.4238816` とする。この二点は約 57.88 m 離れている。
以下ではこの向きをコース軸 `s`、進行左を `d` とする。`s` 軸は ENU で
`(-0.341615, -0.939856)`、`d` 軸は `(+0.939856, -0.341615)` である。

これは競技図と既存シミュレーションの寸法をこの基準線へ投影した可視化・測量案であり、
現地のブイ、桟橋、水深を測った後にのみ実機の目標へ採用する。

## Task 1 — GPS 1→2 のジグザグ、GPS 3→4 の方位標識スラローム

Task 1 の図は、上段で GPS 1→1.1…1.10→GPS 2 を通り、下段で GPS 3→3.1…3.3→GPS 4
へ戻る二本レーンである。既存シミュレーションの `(x,y)` を、GPS 1→2 がちょうど
57.88 m となる倍率 `1.15756` で投影する。下段の3点は方位標識を **S→N→S** の順に
反対側へ通す回避点であり、単なる観測点ではない。

| 区間 | WP | `s, d` [m] |
| --- | --- | ---: |
| 上段 | GPS 1 | `0, 0` |
| 上段 | 1.1〜1.10 | 既存Task1のジグザグ `(10,5)`〜`(40,0)` を1.15756倍 |
| 上段 | GPS 2 | `57.88, 0` |
| 下段 | GPS 3 | `57.88, -28.94` |
| 下段 | 3.1 / 3.2 / 3.3 | `(27.78,-40.51)` / `(17.36,-17.36)` / `(9.26,-40.51)` |
| 下段 | GPS 4 | `0, -28.94` |

## Task 2 — 二つのゲートを結ぶ直進基準線

競技図の赤緑ゲートは幅 5 m、ゲート間隔は 20 m である。GPS 5→6 を直進参照にし、
ゲート中心は `s=18.94 m` と `38.94 m`、各ブイは中心の左右 `d=±2.5 m` に置く。
船のWPは中心線だけを参照し、相手船回避はMPPIが横方向に逃がす。赤・緑端点は地図上の
ゲート確認用であり、通過必須WPにはしない。

## Task 3 — ブイ回廊、ゲート、接岸口、バースを分離

Task 3.1 は既存シミュレーションの図形をそのまま採用し、GPS 7→回廊中心
`(12,0)`→GPS 8ゲート `(18,10)`→接岸口 `(18.25,1.065)`→バース `(20,1.065)`
とする。接岸後は同じ接岸口へ戻る。Task 3.2 は別走行の点対称テンプレートで、GPS 9
から `(-12,0)`、`(-18,-10)`、平行接岸バース `(-20,0)`、GPS 10 `(-18,-11)` へ進む。
ここでも座標は `(s,d)` であり、Task 3.2 はGPS 7と同時には走らせない。

トピック名と完全な緯度経度は `norway_waypoint_publisher` が計算して公開する。例えば
`/visualization/norway_waypoints/task1/wp_1_1`、`.../task2/gate1_center`、
`.../task3_1/berth` で確認できる。
