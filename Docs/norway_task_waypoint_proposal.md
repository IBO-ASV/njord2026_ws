# ノルウェー実海域向け Task 別ウェイポイント案

## 前提

この文書は、次の基準コースを使った**検討用**のウェイポイント案である。実機の
航行設定にはまだ反映しない。ブイ、ゲート、係留場所、航行禁止域および水深を現地で
確認したうえで、最終値を決める。

| 項目 | 緯度, 経度 |
| --- | --- |
| 開始地点 | `63.4420936, 10.4242793` |
| 基準ゴール | `63.4416044, 10.4238816` |

開始地点をローカル ENU 座標の `(0, 0)` とする。`x` は東、`y` は北であり、基準
コースの終点はおよそ `(-19.77, -54.40) m` になる。コース長は約 `57.88 m`、進行
方位は真北基準で約 `199.98°`（ENU yaw では `-1.919 rad`）である。

以下の `s` は開始点からコース方向へ進む距離、`d` は進行方向左側への横オフセット
である。`d > 0` は左、`d < 0` は右を表す。実装時は GNSS のローカル原点・ENU 軸と
一致させること。

## Task 1: 方位標識を見つけて通過

基本は基準線をまっすぐ進み、標識を十分早く検出してから、その指示に応じて迂回する。
標識の向きが確定する前から固定の回避点を入れると誤通過しやすいため、下表の点は
「観測・判断・復帰」の目安として使う。

| 役割 | `s`, `d` [m] | ローカル ENU `x`, `y` [m] | 意図 |
| --- | ---: | ---: | --- |
| entry | `8`, `0` | `(-2.73, -7.52)` | センサ・自己位置の健全性確認 |
| marker-observe | `21`, `0` | `(-7.17, -19.74)` | 方位標識を探索・追跡 |
| decision | `32`, `0` | `(-10.93, -30.08)` | 指示に応じた回避経路へ切替 |
| exit | `47`, `0` | `(-16.06, -44.17)` | 標識通過後に基準線へ復帰 |
| goal | `57.88`, `0` | `(-19.77, -54.40)` | 終点 |

標識を避ける横移動は `decision` の前後で `|d| ≈ 5 m` を出発点とし、実際のブイ間隔と
安全余裕に合わせて決める。左右の符号は画像認識結果と競技ルールから**動的に**選び、
固定 YAML には焼き込まない。

## Task 2: 他船回避

Task 2 は、開始点とゴールを直接結ぶ参照経路を維持し、衝突危険度に応じた横方向の
回避は MPPI に任せる案とする。途中点を通過必須にすると、相手船を避ける余地を狭めて
しまうため、下表は通過条件ではなく監視・再計画の目安である。

| 役割 | `s`, `d` [m] | ローカル ENU `x`, `y` [m] | 意図 |
| --- | ---: | ---: | --- |
| risk-check-1 | `15`, `0` | `(-5.12, -14.10)` | 初期 CPA / 衝突危険度確認 |
| risk-check-2 | `35`, `0` | `(-11.96, -32.89)` | 回避継続・復帰可否の判断 |
| risk-check-3 | `50`, `0` | `(-17.08, -46.99)` | 終盤の再衝突確認 |
| goal | `57.88`, `0` | `(-19.77, -54.40)` | 終点 |

既存の Task 2 シミュレーションと同様、ゴールは基準線上に置いたままにする。相手船の
速度・横切る位置・安全距離に応じて、MPPI が経路を左右へずらし、危険が解消したら
基準線に復帰する。実海域では各 risk-check を「位置だけで停止しないソフトな参照点」
として扱う。

## Task 3: ゲート通過と接岸

Task 3 はゲートと桟橋の実位置・向きが未測量のため、以下を初期レイアウトとして使う。
`gate` を実際のゲート中心へ、`berth` を係留場所の中心へ合わせてから運用する。桟橋の
軸は基準コースと一致するとは限らないため、接岸時の yaw は桟橋の測量方位を使う。

| 役割 | `s`, `d` [m] | ローカル ENU `x`, `y` [m] | 意図 |
| --- | ---: | ---: | --- |
| gate | `24`, `0` | `(-8.20, -22.56)` | ゲート中心の仮置き |
| left-approach | `38`, `+6` | `(-7.34, -37.76)` | 左側バースへの進入開始 |
| left-berth | `45`, `+6` | `(-9.73, -44.34)` | 左側バースの停止位置 |
| right-approach | `38`, `-6` | `(-18.62, -33.66)` | 右側バースへの進入開始 |
| right-berth | `45`, `-6` | `(-21.01, -40.24)` | 右側バースの停止位置 |
| finish | `57.88`, `0` | `(-19.77, -54.40)` | 離岸後の復帰目標 |

運用時は、認識した接岸指定に応じて left または right の一方だけを採用する。`approach`
で低速化し、`berth` の手前で桟橋軸へ船首を合わせ、停止判定後に離岸・`finish` へ向かう。
横オフセット `6 m` は安全な初期値ではなく、船幅、フェンダー、桟橋形状、潮流を踏まえ
て現地で調整する。

## 実機設定へ移す前の確認項目

- GNSS の原点、地図座標、ENU 軸、ヨー角の基準を一致させる。
- ブイ・ゲート・桟橋・浅瀬・立入禁止範囲を測量し、上の仮置き点を置き換える。
- 各停止・接岸点に船体寸法を含む安全余裕を設定する。
- Task 2 は中間監視点をハード制約にせず、回避コストと最小離隔を実船速度で検証する。
- 低速の手動監視試験から始め、ログで CPA、GNSS 誤差、経路追従誤差を確認する。
